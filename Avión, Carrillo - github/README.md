# Sitio web: Clave Segura

Proyecto informativo sobre criptografía realizado con HTML5, CSS3 y JavaScript básico.

## Abrir en Visual Studio Code

1. Abre la carpeta `sitio-criptografia` en Visual Studio Code.
2. Instala la extensión **Live Server** si todavía no la tienes.
3. Haz clic derecho sobre `index.html` y selecciona **Open with Live Server**.

También puedes abrir `index.html` directamente en un navegador.

## Subir a GitHub y publicar con GitHub Pages

1. Descomprime el archivo ZIP. En GitHub, crea un repositorio nuevo para el proyecto.
2. Dentro del repositorio, usa **Add file → Upload files**. Arrastra **el contenido** de la carpeta descomprimida: `index.html`, `html/`, `css/`, `js/`, `img/`, `video/`, `docs/` y este `README.md`. El archivo `index.html` debe quedar al nivel principal del repositorio, no dentro de otra carpeta.
3. Confirma la carga con **Commit changes**. Comprueba que las carpetas conservan su estructura.
4. En **Settings → Pages**, elige **Deploy from a branch** como origen. Selecciona la rama `main` y la carpeta **/(root)**; guarda la configuración.
5. Espera a que GitHub muestre el enlace de la página en esa misma sección. Prueba Inicio, Acerca de, Contacto, el cifrador y el video.

Para compartir el trabajo del grupo, envía el enlace del repositorio. Para mostrar la web terminada, envía el enlace generado en **Pages**. No subas únicamente el ZIP: GitHub necesita los archivos descomprimidos para publicarlos.

## Estructura

- `index.html`: página de inicio.
- `html/acerca-de.html`: información del proyecto.
- `html/contacto.html`: formulario de contacto.
- `css/estilos.css`: diseño completo y responsive.
- `js/app.js`: menú móvil, audio narrado y validación del formulario.
- La página de inicio incluye una demostración interactiva original del cifrado César, inspirada en el proyecto de [accesibleprogramacion](https://github.com/accesibleprogramacion/cifrador-cesar). Se conserva el enlace de atribución en la página.
- `img/`: logo, favicon e infografía.
- `video/criptografia.mp4`: video explicativo integrado en el sitio.
- `docs/TECNICA-DE-DISENO.md`: descripción del wireframe empleado.

> Antes de entregar, reemplaza los datos generales por los apellidos de los dos integrantes y ajusta el correo si corresponde.

Los iconos de redes sociales del pie de página enlazan a la portada de cada plataforma. Si el proyecto tiene perfiles propios, reemplaza las URL en los tres archivos HTML por las direcciones de esos perfiles.
