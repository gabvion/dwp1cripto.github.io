# Técnica de diseño utilizada: wireframe

Antes de desarrollar el sitio se organizó un wireframe de baja fidelidad para definir la jerarquía y el recorrido de cada página.

## Página de inicio

1. Encabezado fijo con logo y menú.
2. Portada con título, explicación breve y demostración visual.
3. Tarjetas de conceptos esenciales.
4. Comparación entre criptografía simétrica y asimétrica.
5. Artículos sobre usos cotidianos y un `aside` con un dato clave.
6. Recurso audiovisual y enlaces externos.
7. Pie de página con navegación y redes sociales.

## Página Acerca de

1. Encabezado y presentación.
2. Propósito del proyecto.
3. Línea del tiempo de la criptografía.
4. Buenas prácticas y llamado a contacto.

## Página Contacto

1. Encabezado y presentación.
2. Información de contacto.
3. Formulario validado.
4. Preguntas frecuentes.

## Decisiones visuales

- Paleta azul noche, turquesa y violeta asociada con tecnología y seguridad.
- Tipografía sans serif para lectura y monoespaciada para etiquetas técnicas.
- Navegación fija, secciones amplias y tarjetas para facilitar el desplazamiento.
- Diseño adaptable para computadoras, tabletas y celulares.
